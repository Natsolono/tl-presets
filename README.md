# Пресеты билдов Throne and Liberty (T2)

Страница с готовыми сборками для конструктора [tl-build.ru](https://tl-build.ru/builder):

- Посох + кинжалы: уворот, устойчивость A, устойчивость B (4 авангард + Рогатый шлем)
- Посох + лук: уворот, устойчивость

Каждая сборка — закладка (bookmarklet): откройте tl-build.ru/builder, нажмите закладку, и билд появится отдельным лоадаутом.
Закладка «📤 Экспорт» сохраняет ваши эксперименты в блок «Мои билды».

Репозиторий хранит только параметры сборок (какие предметы, трейты, руны и узлы мастерства выбраны). Все расчёты делает tl-build.ru.
