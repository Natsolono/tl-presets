Как пользоваться
  1. Перетащите кнопку «⭐ Закладка» нужного билда на панель закладок браузера (Ctrl+Shift+B — показать панель).
  2. Откройте tl-build.ru/builder и нажмите закладку — страница перезагрузится с новым лоадаутом.
  3. Без закладок: «Скопировать скрипт для консоли» → на tl-build.ru нажмите F12 → вкладка Console → вставьте → Enter.
